# M5 and M6 manual checks

M5 and M6's smoke (plan item 16) drove the Release build two ways: the bridged build over the test input bridge (`--test-input-bridge`, file dialogs answered from the bridge's queue), and the normal build through UI Automation patterns only, ending the process with `Stop-Process` to stand in for a crash. Neither way reaches what the items below need:

- The packaged install. The smoke builds the MSIX unsigned and never installs it, so the Start tile, the splash, the jump list, the file association and where the package's local data lands are a person's checks on the dev-signed 5.0.
- The shell and other apps. Task Manager's End task, Explorer's double-click and "Open with", the taskbar's jump list, and a clipboard filled by Edge, the Snipping Tool or Explorer are outside the app.
- What a person judges: Narrator's reading, the caption's snap layouts flyout, a resize by hand.
- Admin tools and a clean machine: the Windows App Certification Kit and Windows Sandbox.

Run the Release build, `dotnet run --project src/RBX15.App/RBX15.App.csproj -c Release --no-build`, at 100% unless the item says otherwise. MAN-11, MAN-12, MAN-16 and MAN-17 need the dev-signed 5.0 MSIX installed (`scripts/build-msix.ps1 -Version 5.0.0.0 -SelfSign`, then install it), and the "Este / release and after certification" list in the M5/M6 plan restores the Store install afterwards. Answer each item pass, fail or not run. MAN-1 to MAN-3 are in [m4a-manual.md](m4a-manual.md), MAN-4 to MAN-9 in [m4b-manual.md](m4b-manual.md).
