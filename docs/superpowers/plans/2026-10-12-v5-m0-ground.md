# RBX15 v5 M0 (Ground) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lay the ground for the native port: move the credential-lifting uploader out of the public repo, stand up the .NET 10 solution with CI, build the golden-image diff and the parity-ledger tooling, and freeze the 4.1 render-core goldens before anything else changes.

**Architecture:** A `src/` .NET solution sits beside the untouched Electron app. `tools/parity-ref` renders scenes through **shipped 4.1 code**: functions are lifted verbatim out of `editor.js` at run time, in Electron with GPU raster off. The renders are committed as frozen goldens. `RBX15.Parity` compares any candidate PNG against a golden using the spec's rule (zero interior differences, edge deltas of 3 or less). `tools/ledger` keeps the 407-row parity ledger honest in CI.

**Tech Stack:** .NET SDK 10.0.203+ (`latestFeature`), C# with nullable enabled and warnings as errors, xUnit 2.9.3, SkiaSharp 4.153.1, WPF (`net10.0-windows`), Node 22 + Electron 41 (reference renderer only), Python 3 stdlib (ledger tool), GitHub Actions `windows-latest`.

**Spec:** [`docs/superpowers/specs/2026-10-11-native-v5-port-design.md`](../specs/2026-10-11-native-v5-port-design.md). Appendices: [`docs/port/parity-ledger.json`](../../port/parity-ledger.json), [`docs/port/divergences.md`](../../port/divergences.md).

**This plan covers M0 only.** M1 to M6 each get their own plan, written when the previous milestone lands, against real code. **Scope note against the spec:** M0 freezes the **render-core** goldens (backgrounds, fills, layers, transforms, adjustments, RGB shift, mask). The Word Art, details, eraser and project round-trip goldens are added to `tools/parity-ref` at the start of M2, which is still before cutover. That's the only place this plan narrows the spec's M0 row.

## Global Constraints

- **Electron is untouched until the cutover PR.** No task in this plan may modify `main.js`, `editor.js`, `editor.html`, `styles.css`, `lib/**`, `packs/**`, `package.json`, `package-lock.json`, `tests/*.test.js` or `windows/**`.
- **Store identity is verbatim:** `Name="626LabsLLC.RBX15ClassicShirtandPantsMaker"`, `Publisher="CN=177BCE59-0966-4975-9962-10E36652141F"`, Store ID `9MV9G4XFJ8S0`. M0 doesn't package anything, but nothing may contradict this.
- **The engine never references WPF.** `RBX15.Engine` targets `net10.0`; only `RBX15.App` targets `net10.0-windows`.
- **SkiaSharp is pinned at `4.153.1`.** Write paths with `SKPathBuilder` (4.x deprecates `SKPath` mutation).
- **The app makes zero network requests.** M0 adds no runtime network code.
- **The golden pass rule** (spec section 6): zero interior differences (pixels whose reference 3x3 neighborhood is one flat color) and edge deltas of 3 or less.
- **Goldens change only on purpose.** CI never regenerates them; only `tools/parity-ref` run by a person does.
- **Repo conventions:** conventional commits; branches and PRs into `main`; Windows paths in docs as `C:\...`, commands use forward slashes.
- **Dashboard:** log a decision on any fork (project `6KpHItSNg9NYHkJg9thn`, origin `Dunder · Claude Code`).

## Review Focus

- **Function extraction silently grabbing the wrong span of `editor.js`.** A later edit could make a regex match a different function, producing goldens of the wrong code. Expected: the renderer refuses to run unless every lifted function is found exactly once and compiles. Pinned in Task 6, Step 1 (`extractShipped` tests).
- **Goldens that differ by machine (GPU raster, driver).** Expected: two renders of the same scene are byte-identical on one machine, and the index records Electron/Chrome versions plus the `editor.js` blob hash. Pinned in Task 6, Step 1 (determinism test) and Task 7 (`index.json` provenance).
- **Git rewriting PNG bytes (autocrlf, text normalization).** Expected: goldens round-trip through git unchanged. Pinned in Task 7, Step 1 (`.gitattributes`, checked with `git check-attr`).
- **Hand edits to `parity-ledger.md` drifting from the JSON.** Expected: CI fails when the committed Markdown isn't the rendered JSON. Pinned in Task 4 (`test_check_flags_stale_markdown`).
- **Fully transparent pixels that differ only in hidden RGB.** PNG stores color under alpha 0 that nobody sees, so a naive diff fails identical-looking images. Expected: two alpha-0 pixels are equal regardless of RGB. Pinned in Task 5 (`Transparent_pixels_with_different_rgb_are_equal`).

```python
"""The v5 parity ledger: validate it and render its Markdown views.

    python tools/ledger/ledger.py check    # exit 1 and list problems if anything is off
    python tools/ledger/ledger.py render   # rewrite docs/port/*.md from parity-ledger.json

parity-ledger.json is the source of truth. The two Markdown files are generated
views; editing them by hand is a check failure.
"""
from __future__ import annotations

import collections
import json
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[2]
PORT = ROOT / "docs" / "port"

OWNERS = {
    "Engine.Template", "Engine.Document", "Engine.Render", "Engine.Fills", "Engine.Adjust",
    "Engine.WordArt", "Engine.Details", "Engine.Tools", "Engine.History", "Engine.ProjectIO",
    "Engine.Export", "App.Shell", "App.Ribbon.Home", "App.Ribbon.Layout", "App.Ribbon.Details",
    "App.Ribbon.Text", "App.Layers", "App.LayerProperties", "App.AssetLibrary", "App.Canvas",
    "App.Keyboard", "App.Dialogs", "App.Storage", "App.Clipboard", "Package", "Docs", "Parity",
    "Retired",
}
CHECKS = {"unit", "golden", "ui-auto", "manual", "doc", "none-retired"}
DISPOSITIONS = {"keep", "fix", "drop", "new"}
STATUSES = {"open", "done"}


def load(path: Path) -> dict:
    return json.loads(Path(path).read_text(encoding="utf-8"))


def cell(s) -> str:
    return " ".join(str(s).split()).replace("|", "\\|")


def render_ledger(data: dict) -> str:
    rows = data["rows"]
    by_owner = collections.defaultdict(list)
    for r in rows:
        by_owner[r["owner"]].append(r)
    disp = collections.Counter(r["disposition"] for r in rows)
    checks = collections.Counter(r["check"] for r in rows)
    status = collections.Counter(r["status"] for r in rows)
    out = [
        "# Parity ledger", "",
        "Generated from `parity-ledger.json` by `tools/ledger/ledger.py render` (do not edit by hand). "
        "Every user-visible behavior of RBX15 4.1, inventoried 2026-10-11, with the module that owns it in v5, "
        "how parity is proven, and whether v5 keeps it, fixes it, drops it, or adds it. "
        "**v5 does not ship with a row whose status is `open`.** Design: "
        "[native v5 port design](../superpowers/specs/2026-10-11-native-v5-port-design.md). "
        "Deliberate changes: [divergences](divergences.md).", "",
        f"**{len(rows)} rows.** Status: " + ", ".join(f"{k} {v}" for k, v in sorted(status.items())) +
        ". Disposition: " + ", ".join(f"{k} {v}" for k, v in disp.most_common()) +
        ". Checks: " + ", ".join(f"{k} {v}" for k, v in checks.most_common()) + ".", "",
    ]
    for owner in sorted(by_owner):
        out += [f"## {owner}", "", "| Status | ID | Behavior | Check | Disposition | Risk |",
                "|---|---|---|---|---|---|"]
        out += [f"| {r['status']} | `{r['id']}` | {cell(r['name'])} | {r['check']} | {r['disposition']} | {r['risk']} |"
                for r in by_owner[owner]]
        out.append("")
    return "\n".join(out)


def render_divergences(data: dict) -> str:
    rows = data["rows"]
    out = [
        "# Divergences from 4.1", "",
        "Every deliberate behavior change in v5, generated from `parity-ledger.json` rows whose disposition is "
        "`fix` or `drop`. The bug policy: fix anything clearly unintended, keep anything a user could reasonably "
        "rely on. A change that is not in this table is a regression. Rows with a visual effect get a new golden "
        "image with a note.", "",
    ]
    for kind, title in (("fix", "Fixed in v5"), ("drop", "Not carried into v5")):
        rs = sorted((r for r in rows if r["disposition"] == kind), key=lambda r: (r["owner"], r["id"]))
        out += [f"## {title} ({len(rs)})", "", "| ID | Owner | Change |", "|---|---|---|"]
        out += [f"| `{r['id']}` | {r['owner']} | {cell(r['divergence'])} |" for r in rs]
        out.append("")
    new = [r for r in rows if r["disposition"] == "new"]
    if new:
        out += [f"## New in v5 ({len(new)})", "", "| ID | Owner | Behavior |", "|---|---|---|"]
        out += [f"| `{r['id']}` | {r['owner']} | {cell(r['name'])} |" for r in new]
        out.append("")
    return "\n".join(out)


def problems(data: dict, md_dir: Path) -> list[str]:
    found: list[str] = []
    seen = collections.Counter(r["id"] for r in data["rows"])
    found += [f"duplicate id {i}" for i, n in seen.items() if n > 1]
    for r in data["rows"]:
        rid = r["id"]
```

```csharp
using SkiaSharp;

namespace RBX15.Parity;

public sealed record DiffResult(bool SameSize, int MaxDelta, int DifferingPixels, int InteriorDifferences,
                                int EdgeOverTolerance, bool Pass);

/// <summary>
/// The v5 golden rule (spec section 6): zero differences on interior pixels, where a pixel is interior
/// when its reference 3x3 neighborhood is one flat color, and edge deltas of at most
/// <c>edgeTolerance</c>. Delta is the largest absolute RGBA channel difference on un-premultiplied
/// values. Two fully transparent pixels are equal whatever RGB they store.
/// </summary>
public static class ImageDiff
{
    public static SKBitmap Load(string path)
    {
        using var decoded = SKBitmap.Decode(path) ?? throw new InvalidOperationException($"cannot decode {path}");
        return Normalize(decoded);
    }

    static SKBitmap Normalize(SKBitmap b)
    {
        var info = new SKImageInfo(b.Width, b.Height, SKColorType.Rgba8888, SKAlphaType.Unpremul);
        if (b.Info.ColorType == info.ColorType && b.Info.AlphaType == info.AlphaType) return b.Copy();
        var dst = new SKBitmap(info);
        if (!b.CopyTo(dst, SKColorType.Rgba8888)) throw new InvalidOperationException("pixel conversion failed");
        return dst;
    }

    static int Delta(SKColor a, SKColor b)
    {
        if (a.Alpha == 0 && b.Alpha == 0) return 0;
        return Math.Max(Math.Max(Math.Abs(a.Red - b.Red), Math.Abs(a.Green - b.Green)),
                        Math.Max(Math.Abs(a.Blue - b.Blue), Math.Abs(a.Alpha - b.Alpha)));
    }

    static bool IsInterior(SKBitmap reference, int x, int y)
    {
        if (x == 0 || y == 0 || x == reference.Width - 1 || y == reference.Height - 1) return false;
        var center = reference.GetPixel(x, y);
        for (int dy = -1; dy <= 1; dy++)
            for (int dx = -1; dx <= 1; dx++)
                if (Delta(reference.GetPixel(x + dx, y + dy), center) != 0) return false;
        return true;
    }

    public static DiffResult Compare(SKBitmap reference, SKBitmap candidate, int edgeTolerance = 3)
    {
        if (reference.Width != candidate.Width || reference.Height != candidate.Height)
            return new DiffResult(false, 255, -1, -1, -1, false);
        using var a = Normalize(reference);
        using var b = Normalize(candidate);
        int max = 0, differing = 0, interior = 0, edgeOver = 0;
        for (int y = 0; y < a.Height; y++)
            for (int x = 0; x < a.Width; x++)
            {
                int d = Delta(a.GetPixel(x, y), b.GetPixel(x, y));
                if (d == 0) continue;
                differing++;
                max = Math.Max(max, d);
                if (IsInterior(a, x, y)) interior++;
                else if (d > edgeTolerance) edgeOver++;
            }
        return new DiffResult(true, max, differing, interior, edgeOver, interior == 0 && edgeOver == 0);
    }

    public static SKBitmap Heatmap(SKBitmap reference, SKBitmap candidate)
    {
        using var a = Normalize(reference);
        using var b = Normalize(candidate);
        var heat = new SKBitmap(new SKImageInfo(a.Width, a.Height, SKColorType.Rgba8888, SKAlphaType.Unpremul));
        for (int y = 0; y < a.Height; y++)
            for (int x = 0; x < a.Width; x++)
            {
                int d = Delta(a.GetPixel(x, y), b.GetPixel(x, y));
                byte v = (byte)Math.Min(255, d * 16);
                heat.SetPixel(x, y, d == 0 ? SKColors.White : new SKColor(255, (byte)(255 - v), (byte)(255 - v)));
            }
        return heat;
    }
}
```

```js
// Lifts the shipped render code out of editor.js, verbatim, so goldens are made by
// the code 4.1 actually ships rather than a re-implementation of it. Every piece must
// be found exactly once; anything else throws, so editor.js drift can't silently
// produce goldens of the wrong code.
const FUNCTIONS = ['unionRect', 'connectedRegionGroups', 'paintRegions', 'applyRGBShift',
  'hasAdjustments', 'drawLayerWithAdjustments', 'buildMask'];

function once(src, re, what) {
  const all = [...src.matchAll(new RegExp(re.source, re.flags.includes('g') ? re.flags : re.flags + 'g'))];
  if (all.length !== 1) throw new Error(`parity-ref: ${what} ${all.length ? 'found ' + all.length + ' times' : 'not found'} in editor.js`);
  return all[0][0];
}

function extractShipped(editorSource) {
  const src = editorSource.replace(/\r\n/g, '\n');
  const constants = [
    once(src, /^const TW = 585, TH = 559;$/m, 'TW/TH'),
    once(src, /^const SHIRT_REGION_DATA = \{[\s\S]*?\n\};$/m, 'SHIRT_REGION_DATA'),
    once(src, /^const PANTS_REGION_DATA = \{[\s\S]*?\n\};$/m, 'PANTS_REGION_DATA'),
  ].join('\n');
  const functions = {};
  for (const name of FUNCTIONS) {
    functions[name] = once(src, new RegExp(`^function ${name}\\([\\s\\S]*?\\n\\}$`, 'm'), `function ${name}`);
  }
  const start = src.indexOf('  ec.clearRect(0, 0, TW, TH);');
  const end = src.indexOf('  const link = document.createElement', start);
  if (start < 0 || end < 0 || src.indexOf('  ec.clearRect(0, 0, TW, TH);', start + 1) >= 0) {
    throw new Error('parity-ref: exportPNG composition body not found exactly once in editor.js');
  }
  return { constants, functions, exportBody: src.slice(start, end) };
}

module.exports = { extractShipped, FUNCTIONS };
```

```js
function dataUrl(rel) {
  const file = path.join(ROOT, rel);
  if (!fs.existsSync(file)) throw new Error(`scene image not found: ${rel}`);
  return 'data:image/png;base64,' + fs.readFileSync(file).toString('base64');
}

function blob(rel) {
  return execFileSync('git', ['hash-object', rel], { cwd: ROOT, encoding: 'utf8' }).trim();

    const scenesFile = arg('--scenes');
    const out = arg('--out');
    if (!scenesFile || !out) throw new Error('usage: --scenes <file> --out <dir> [--only a,b]');
    let scenes = JSON.parse(fs.readFileSync(path.resolve(scenesFile), 'utf8'));
    const only = arg('--only');
    if (only) scenes = scenes.filter((s) => only.split(',').includes(s.name));
    const names = scenes.map((s) => s.name);
    if (new Set(names).size !== names.length) throw new Error('duplicate scene names');
    fs.mkdirSync(path.resolve(out), { recursive: true });

    const win = new BrowserWindow({ show: false, webPreferences: { contextIsolation: false } });

      electron: process.versions.electron, chrome: process.versions.chrome,
```

```markdown
# tools/parity-ref

Renders parity scenes through shipped 4.1 code, lifted verbatim out of `editor.js` by `extract.js`, in Electron with GPU raster off. The output is the frozen golden set the native v5 engine is held to (spec section 6).

## Rules

- Goldens in `tests/goldens/` are made **only** by this tool, run by a person. CI never regenerates them.
- They are frozen from 4.1. Regenerating them after `editor.js` changes is wrong unless the change is a 4.x release the native port must also match.
- A deliberate v5 divergence with a visual effect gets a **new** golden next to the 4.1 one, plus a note in `docs/port/divergences.md`. The 4.1 golden is never overwritten.
- This directory is deleted at cutover. The goldens stay.

    node --test tools/parity-ref/                     # the tool's own tests

`index.json` records the Electron and Chrome versions, the git blob hashes of `editor.js` and `lib/fills.js`, and each PNG's SHA-256.

`{ name, mode?, bgColor?, bgOpacity?, bgImage?, regionColors?, layers?: [{ image, x?, y?, scale?, rotation?, flipH?, flipV?, opacity?, visible?, brightness?, contrast?, saturate?, hueRotate?, rShift?, gShift?, bShift? }] }`.
```
