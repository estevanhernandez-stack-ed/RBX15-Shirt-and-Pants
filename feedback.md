# feedback.md — bug reports & user feedback

> Seeded 2026-07-21 from the full-code audit (The Architect, RBX15 revival session).
> These four are confirmed-in-code findings cited to file:line — not end-user reports.
> Each finding names the v5 regression test that now guards it. Add real user reports below as they arrive (one per line, optional [severity] tag).

[fixed in PR #27] bug: [critical] Layer name is interpolated unescaped into innerHTML (editor.js:674, `value="${sel.name}"`). With nodeIntegration:true + contextIsolation:false (main.js:10-11), a crafted asset filename executes code with Node access the moment the layer is selected. v5 tests: Engine.Tests `LayerOpsEditTests.SetName_takes_any_text` (a name like `drip <b>` is kept as plain text) and `ProjectIOTests.A_built_document_round_trips_including_a_semi_transparent_image` (the name `Soft "quoted" <b>` survives a save and reload). v5 has no HTML to inject into: the app binds names as text.
[fixed in PR #25] bug: [major] Asset browser click-to-add is broken — `clickName` is undefined at editor.js:2232 (variable in scope is `displayName`). Every thumbnail click throws a ReferenceError inside img.onload and no layer is added. Happens every time; advertised README feature. v5 test: App.Tests `AssetLibraryViewModelTests.A_click_adds_the_file_fit_in_the_front_slot_as_one_step`.
[fixed in PR #26] bug: [major] Eraser tool is a no-op — destination-out strokes land on an empty offscreen canvas (editor.js:1027-1035), so the mouseup content check finds nothing and discards the stroke. E key and button both dead. Happens every time; advertised README feature. v5 tests: Engine.Tests `EraserTests.Erases_stroked_pixels_at_identity_and_leaves_the_rest` and App.Tests `LedgerScenarioTests.The_eraser_refuses_without_a_selection_and_erases_only_the_selected_layer_even_when_hidden`.
[fixed in PR #28] bug: [minor] No redo, and undo doesn't cover region fills, background changes, or mode switches — toggling Shirt/Pants wipes all region colors irrecoverably (editor.js:1457). v5 tests: Engine.Tests `HistoryTests.Redo_brings_back_the_state_undo_parked` and App.Tests `LedgerScenarioTests.Mode_switch_wipes_fills_keeps_layers_and_undo_brings_the_fills_back`.
